# DECANTS PARANA — versión Netlify

Catálogo de decants con panel administrativo privado.

### Backend
- Netlify Functions
- Netlify Blobs
- Sin Supabase ni bases externas

### Panel
Abrir `/admin`.

Configurar en Netlify las variables `LAUREANO_ADMIN_USER=laureano`, `LAUREANO_ADMIN_PASSWORD=laucha` y `ADMIN_SESSION_SECRET`.

Ver `README_NETLIFY.md` para la instalación completa.
